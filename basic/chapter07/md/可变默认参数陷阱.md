# 可变默认参数陷阱（mutable default argument）

> 存放位置：`basic\chapter07\md\可变默认参数陷阱.md`
> 前置知识：函数默认参数、可变与不可变对象、`is`/`==`（见同章 `is与等于号区别及intern机制.md`）
> 配套验证：本文所有代码与结论均在 `D:\python\fastapi_test\.venv`（Python 3.13）实测通过

## 一句话结论

**可变对象（list/dict/set 等）不能直接做函数默认参数**：默认值在 `def` 定义时**只求值一次**，之后每次不传参调用拿到的都是**同一个对象**——一个实例改它，所有实例一起变。标准修法是 **None 哨兵** + 函数体内新建。

## 1. 问题代码与实测

```python
class Company:
    def __init__(self, name, staffs=[]):   # ← 陷阱：可变默认参数
        self.name = name
        self.staffs = staffs

    def add(self, staff_name):
        self.staffs.append(staff_name)

c1 = Company("A")
c2 = Company("B")
c1.add("张三")

print(c1.staffs)                    # ['张三']
print(c2.staffs)                    # ['张三'] ← 张三"泄漏"到 B 公司！
print(c1.staffs is c2.staffs)       # True  ← 两个实例拿着同一个列表
print(Company.__init__.__defaults__)  # (['张三'],) ← 默认值本体也被污染
```

实测输出：

```
c1.staffs: ['张三']
c2.staffs: ['张三']
c1.staffs is c2.staffs: True
__init__.__defaults__: (['张三'],)
默认值 id == c1.staffs id          # id 完全一致，确认是同一个对象
```

## 2. 原理：默认值只在 `def` 时求值一次

```python
def __init__(self, name, staffs=[]):
```

Python 在执行 `def` 语句时创建函数对象，同时把默认值表达式**一次性求值**，存进函数的 `__defaults__` 元组。之后每次调用：

- 传了 `staffs` → 用传入的；
- 没传 → **直接拿 `__defaults__` 里那个现成的 list**。

所以 `Company("A")`、`Company("B")` 未传参时，`self.staffs` 都指向 `__defaults__[0]`——同一个列表。`c1.add()` 的 `append` 改的就是它。

注意与不可变默认参数的区别：`staffs=()`（元组）没问题，因为元组不可变、改不坏——但语义仍是"所有实例共享"，当列表用依然不合适。

## 3. 正确写法：None 哨兵

```python
class Company:
    def __init__(self, name, staffs=None):
        self.name = name
        self.staffs = staffs if staffs is not None else []   # 每次调用新建列表

    def add(self, staff_name):
        self.staffs.append(staff_name)

d1 = Company("A")
d2 = Company("B")
d1.add("张三")
print(d1.staffs, d2.staffs)          # ['张三'] []  ← 互不影响
print(d1.staffs is d2.staffs)        # False
```

### 方案对比

| 方案 | 写法 | 评价 |
|---|---|---|
| 直接 `staffs=[]` | 错误 | 实例共享同一个列表，数据互相污染 |
| **None 哨兵** | `staffs=None` + 函数内建新列表 | ✅ 标准做法，兼容显式传列表的场景 |
| 不可变默认值 | `staffs=()`（元组） | 只是"改不坏"，语义仍是共享，不推荐 |
| 类型标注版 | `staffs: list[str] \| None = None` | None 哨兵的现代写法（Python 3.10+） |

## 4. 延伸：同样的问题不止 list

1. **一切可变对象都不能做默认值**：`dict`、`set`、自定义对象、`bytearray` 全有同类陷阱。

```python
def log(msg, tags=set()):      # 陷阱
    tags.add(msg)

def log(msg, tags=None):       # 正确
    tags = set() if tags is None else tags
    tags.add(msg)
```

2. **类属性同理**：`class Company: staffs = []` 是所有实例共享一个列表（这是类属性的语义，**有时是有意为之**——共享状态）；想"每个实例独立"，必须在 `__init__` 里赋值。

```python
class A:
    items = []          # 所有实例共享（类属性）
    def __init__(self):
        self.own = []   # 每个实例独立（实例属性）
```

3. **面试高频**：这个陷阱常作为 Python 面试题，考察对"默认参数求值时机"和"可变/不可变"双重理解的深度。

## 5. 一句话记忆

> **默认值在 `def` 时只创建一次；可变默认值 = 所有不传参的调用共享同一个可变对象 = 必然互相污染。** 凡是"每个调用都要独立的新容器"，就用 `None` 哨兵在函数体内新建。
