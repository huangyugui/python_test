# `is` 与 `==` 的区别，以及字符串 intern 机制

> 存放位置：`basic\chapter07\md\is与等于号区别及intern机制.md`
> 前置知识：对象模型（身份/类型/值）、`id()`、可变与不可变对象
> 配套验证：本文所有代码与结论均在 `D:\python\fastapi_test\.venv`（Python 3.13）实测通过

## 一句话结论

**`==` 比较"值"，`is` 比较"身份"（内存地址）**：

- `a == b` → 调用 `type(a).__eq__(a, b)`，比较**内容是否相等**（可被自定义语义覆写）。
- `a is b` → 等价于 `id(a) == id(b)`，比较**是不是同一个对象**（任何类都无法覆写）。
- **intern 机制**：解释器/`sys.intern()` 把某些不可变对象（小整数、字符串）缓存成"单例"，让重复出现的相同值**共享同一个对象**——于是 `is` 对它们也能为 True。

---

## 1. `is` vs `==` 对比表

| 维度 | `==` | `is` |
|---|---|---|
| 比较什么 | 值（内容） | 身份（内存地址） |
| 底层机制 | `__eq__` 方法（可覆写） | `id(a) == id(b)`（不可覆写） |
| 判断问题 | "这俩一样吗？" | "这俩是同一个东西吗？" |
| 典型用途 | 数值、字符串、容器内容比较 | `None` 判断、单例判断、类比较 |
| 结果语义 | 可被自定义（`__eq__` 返回 True 即可） | 绝对客观（同一对象才 True） |
| 性能 | O(n)（长字符串/大容器逐项比较） | **O(1)**（指针比较） |

```python
# 本质演示
class P:
    def __eq__(self, other):
        return True          # 值上"什么都相等"

p1, p2 = P(), P()
print(p1 == p2)   # True  ← __eq__ 说了算
print(p1 is p2)   # False ← 两个对象，id 不同，is 不买账
```

## 2. intern 机制：为什么 `is` 有时也是 True

正常情况下 `is` 对两个"相等但分开创建"的对象应为 False。但 Python 有一个**缓存/单例机制（intern）**，让部分不可变对象"同名同对象"：

### 2.1 小整数缓存（-5 ~ 256）

CPython 启动时把 `-5` 到 `256` 的整数全部预建为单例，此后任何地方引用这些值都拿到**同一个对象**：

```python
a, b = 100, 100
print(a is b)   # True  ← 都在缓存区间，是同一个对象

e, f = 257, int("257")
print(e is f)   # False ← 257 不在缓存区间，int("257") 运行时新建
print(e == f)   # True  ← 值相等
```

⚠️ **一个容易误解的细节**：同一段代码里写 `c, d = 257, 257`，实测 `c is d` 是 **True**——这**不是**缓存，而是**编译期常量合并**（编译器把同一代码块内相同的字面量折叠成同一个常量对象）。要验证"257 无缓存"必须用运行时构造（如 `int("257")`）绕开合并。

### 2.2 字符串 intern

- **自动 intern**：编译期出现的字符串字面量会被合并缓存（`"hello"` 写两次是同一对象）；标识符名、空串也是。
- **运行时构造不 intern**：`"".join(...)`、切片、`str()` 等运行时产生的字符串默认是新对象（个别短串有解释器级优化，不可依赖）。

```python
s1, s2 = "hello", "hello"
print(s1 is s2)   # True  ← 字面量被编译期合并 + intern

s3 = "".join(["h", "e", "l", "l", "o"])   # 运行时构造
print(s3 is s1)   # False ← 新对象
print(s3 == s1)   # True  ← 值相等
```

- **手动 intern**：`sys.intern(s)` 把字符串放入解释器级 intern 池，之后所有相同内容的 `sys.intern` 调用都返回同一对象：

```python
import sys
print(sys.intern(s3) is sys.intern(s1))   # True ← 都进了 intern 池
```

**intern 的两个收益**：

1. **省内存**：大量重复字符串只存一份（字典键、标识符、协议字段名的经典场景）。
2. **`is` 比较 O(1)**：指针相等一次判定，代替逐字符 O(n) 比较（且绝对无副作用，不依赖 `__eq__`）。

### 2.3 其他单例

- `None`：语言级单例，判断必须用 `is None`。
- 布尔值 `True`/`False`、`NotImplemented`、`Ellipsis`：同样单例。

```python
x = None
print(x is None)   # True ← 唯一合法姿势
```

## 3. 完整实测（Python 3.13）

```
100 is 100: True                       # 小整数缓存
257 is 257（同字面量）: True           # 编译期常量合并（非缓存！）
257 vs int('257'): False | ==: True    # 运行时构造 → 新对象
字面量 hello is hello: True            # 编译期合并 + intern
join结果 is 字面量: False | ==: True   # 运行时构造 → 新对象
sys.intern 后 is: True                 # 手动 intern 池
None is None: True                     # 单例
自定义对象 ==: True | is: False        # __eq__ 可覆写，is 不可
id 验证 is 的本质: False               # is 即 id 比较
```

## 4. 场景与坑

### 4.1 该用哪个

| 场景 | 用 | 理由 |
|---|---|---|
| `None` / `True` / `False` / 单例 | **`is`** | 单例身份，O(1)，语义正确 |
| 数值、字符串、容器比较 | **`==`** | 比的是值；`is` 依赖缓存，不可靠 |
| 类对象比较 | **`is`** | `MyClass is MyClass` 身份唯一 |
| 判断变量是否"同一个对象" | **`is`** | 别名检测（如 `a is b` 判断共享引用） |

### 4.2 三个经典坑

1. **依赖 `is` 比较字符串/整数**：`a is b` 对短字符串、小整数可能意外为 True（缓存），但对运行时构造的同值对象是 False——**跨文件、跨模块、经过函数传参后一切缓存假设都可能失效**，数值/字符串永远用 `==`。
2. **可变对象不可作为 intern 目标**：intern 依赖"不可变才有唯一实例"的语义；list/dict 每次创建都是新对象，`is` 必为 False。
3. **`==` 被覆写后可能"谎报"**：自定义 `__eq__` 可以让任何两个对象相等；需要绝对身份判断时用 `is`（PEP 8 也建议单例比较用 `is`）。

### 4.3 性能视角

- 字符串海量比较：`intern` 后 `is` 比 `==` 快一个数量级（O(1) vs O(n)）——协议字段名、字典键热路径可考虑 `sys.intern`。
- 但 intern 本身有成本（查池、驻留内存），只对**重复率高**的字符串值钱；随手 intern 反而浪费。

## 5. 一句话记忆

> **`==` 问"值一样吗"（`__eq__` 说了算，可能 O(n)），`is` 问"是同一个吗"（`id` 说了算，恒 O(1)）**；小整数、字符串字面量被 intern 成单例，是 `is` 偶尔为 True 的原因——**判 None 用 `is`，比内容用 `==`**。
