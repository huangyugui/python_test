## 1. 对象生命周期

| 魔法函数 | 触发方式 | 作用 |
|---|---|---|
| `__new__` | `类(...)` 创建实例时 | 创建并返回新实例（比 `__init__` 更早，常用于不可变类型、单例） |
| `__init__` | 实例创建后 | 初始化实例属性 |
| `__del__` | 对象被回收时 | 清理资源（不保证一定执行，慎用） |

```python
class Person:
    def __new__(cls, name):
        print("1. __new__ 创建实例")
        instance = super().__new__(cls)
        return instance

    def __init__(self, name):
        print("2. __init__ 初始化")
        self.name = name

    def __del__(self):
        print("3. __del__ 对象销毁")

p = Person("张三")
# 1. __new__ 创建实例
# 2. __init__ 初始化
del p
# 3. __del__ 对象销毁
```

## 2. 字符串表示

| 魔法函数 | 触发方式 | 作用 |
|---|---|---|
| `__str__` | `str(obj)`、`print(obj)` | 面向用户的友好可读描述 |
| `__repr__` | `repr(obj)`、交互式终端直接输对象名 | 面向开发者的精确描述，理想上可用 `eval()` 还原 |

```python
class Company:
    def __init__(self, name, employees):
        self.name = name
        self.employees = employees

    def __str__(self):
        return f"公司: {self.name}, 员工: {self.employees}"

    def __repr__(self):
        return f"Company(name={self.name!r}, employees={self.employees!r})"

c = Company("字节", ["jone", "tom"])
print(str(c))    # 公司: 字节, 员工: ['jone', 'tom']
print(repr(c))   # Company(name='字节', employees=['jone', 'tom'])
```

**要点**：
- 只实现一个时优先 `__repr__`，`print` 会退化使用它
- 容器（列表、字典）打印元素时用的是 `__repr__` 而不是 `__str__`

## 3. 容器与序列协议

让对象支持 `[]` 下标、`len()`、`in` 等容器语法。

| 魔法函数 | 触发方式 | 作用 |
|---|---|---|
| `__len__` | `len(obj)`、`bool(obj)` | 返回长度 |
| `__getitem__` | `obj[key]` | 取值 |
| `__setitem__` | `obj[key] = value` | 赋值 |
| `__delitem__` | `del obj[key]` | 删除 |
| `__contains__` | `key in obj` | 成员判断 |
| `__reversed__` | `reversed(obj)` | 反向迭代 |

```python
class MyList:
    def __init__(self, items):
        self._items = list(items)

    def __len__(self):
        return len(self._items)

    def __getitem__(self, index):
        return self._items[index]

    def __setitem__(self, index, value):
        self._items[index] = value

    def __delitem__(self, index):
        del self._items[index]

    def __contains__(self, item):
        return item in self._items

    def __reversed__(self):
        return reversed(self._items)

    def __iter__(self):
        return iter(self._items)

ml = MyList([1, 2, 3])
print(len(ml))          # 3       → __len__
print(ml[0])            # 1       → __getitem__
ml[0] = 100             #         → __setitem__
del ml[1]               #         → __delitem__
print(2 in ml)          # False   → __contains__
print(list(reversed(ml)))  # [3, 100] → __reversed__
```

**要点**：
- 定义了 `__getitem__` 后，`for` 循环、`in` 判断会自动退化使用它（从下标 0 开始取直到 IndexError）
- 想精确控制 `in` 的语义（如字符串包含、模糊匹配），显式实现 `__contains__`

## 4. 迭代协议

| 魔法函数 | 触发方式 | 作用 |
|---|---|---|
| `__iter__` | `iter(obj)`、`for x in obj` | 返回迭代器对象 |
| `__next__` | `next(obj)`、for 循环每轮取值 | 返回下一个值，没有时抛 `StopIteration` |

```python
class Countdown:
    def __init__(self, start):
        self.current = start

    def __iter__(self):
        return self                 # 自身就是迭代器

    def __next__(self):
        if self.current <= 0:
            raise StopIteration     # 结束信号
        value = self.current
        self.current -= 1
        return value

for n in Countdown(3):
    print(n)   # 3 2 1
```

**两种迭代器形态**：
- **迭代器**（自身实现 `__iter__` + `__next__`）：有状态、可消费一次，如 `Countdown`
- **可迭代对象**（只实现 `__iter__` 返回独立迭代器）：可重复遍历，如列表

### 可迭代对象（Iterable） vs 迭代器（Iterator）

这是 Python 中最容易混淆的两个概念，本质区别在于**谁有状态、能不能重复遍历**：

| 维度 | 可迭代对象（Iterable） | 迭代器（Iterator） |
|---|---|---|
| 定义 | 实现了 `__iter__` 的对象 | 实现了 `__iter__` + `__next__` 的对象 |
| 核心职责 | 提供迭代器（"能给我一个迭代器"） | 自己迭代（"我逐个产生值"） |
| 是否可重复遍历 | ✅ 每次 `iter(obj)` 拿到**新的**迭代器，可反复遍历 | ❌ 有内部状态，消费一次就耗尽 |
| 是否自带取值逻辑 | ❌ 本身不产生值，要问迭代器要 | ✅ `next()` 直接产生下一个值 |
| `iter(obj)` 返回 | 返回一个迭代器（常常不是自己） | 返回自己（`return self`） |
| 典型例子 | `list`、`tuple`、`str`、`dict`、`set` | `range` 对象不是迭代器，`zip`、`enumerate`、生成器是 |
| 一次性用完？ | 可以用很多次 | 只能向前走，不能回头 |

**判断方式**：

```python
from collections.abc import Iterable, Iterator

lst = [1, 2, 3]
print(isinstance(lst, Iterable))   # True  列表是可迭代对象
print(isinstance(lst, Iterator))   # False 但列表本身不是迭代器

it = iter(lst)                     # 用 iter() 从列表取出迭代器
print(isinstance(it, Iterator))    # True
print(next(it))                    # 1
print(next(it))                    # 2
print(next(it))                    # 3
# print(next(it))                  # StopIteration：耗尽后继续取会抛异常
```

**重复遍历 vs 一次性消费**：

```python
# 可迭代对象：可以多次 for
for x in [1, 2, 3]:
    pass
for x in [1, 2, 3]:      # 第二遍照样有数据
    pass

# 迭代器：用一次就没了
it = iter([1, 2, 3])
print(list(it))          # [1, 2, 3]
print(list(it))          # []  第二次为空，因为迭代器已被耗尽
```

**for 循环背后到底做了什么**：

```python
for x in obj:
    print(x)

# 等价于：
iterator = iter(obj)      # 1. 调用 obj.__iter__() 拿到迭代器
while True:
    try:
        x = next(iterator)   # 2. 反复调用 iterator.__next__()
    except StopIteration:    # 3. 遇到 StopIteration 结束循环
        break
    print(x)
```

**为什么列表同时是"可迭代对象"但"不是迭代器"**：因为列表的 `__iter__` 返回的是一个新的 `list_iterator`，而不是自己——所以每次遍历都从新迭代器开始，数据不会丢失。

**常见误区**：
- `range(3)` 是可迭代对象（能被 `iter()`），但它本身不是迭代器（`next(range(3))` 会报错），得先 `iter(range(3))`
- 生成器（生成器函数、生成器表达式）本身就是迭代器，天然只能消费一次
- `dict` 迭代的是键，`enumerate` 迭代的是 `(索引, 元素)` 元组

## 5. 上下文管理器

让对象支持 `with` 语句，自动处理资源获取与释放。

| 魔法函数 | 触发方式 | 作用 |
|---|---|---|
| `__enter__` | `with` 进入时 | 准备资源，返回值赋给 `as` 变量 |
| `__exit__` | `with` 代码块结束时（正常/异常都会执行） | 清理资源；返回 `True` 吞掉异常，`False`/`None` 让异常继续抛出 |

```python
class FileManager:
    def __init__(self, path):
        self.path = path

    def __enter__(self):
        print(">>> 打开文件")
        self.f = open(self.path, "w")
        return self.f               # as 拿到返回值

    def __exit__(self, exc_type, exc_val, exc_tb):
        print(">>> 关闭文件")
        self.f.close()
        return False                # 异常不吞，继续抛出

with FileManager("test.txt") as f:
    f.write("hello")
```

**`__exit__` 三参数 + 返回值**：

| 参数/返回值 | 含义 |
|---|---|
| `exc_type` | 异常类型（无异常为 None） |
| `exc_val` | 异常实例 |
| `exc_tb` | traceback 对象 |
| 返回 `True` | 异常被吞掉，代码继续执行 |
| 返回 `False` / `None` | 异常向上传播 |

**快捷替代**：用 `@contextmanager`（同步）或 `@asynccontextmanager`（异步）装饰生成器，`yield` 前对应 `__enter__`，`yield` 后对应 `__exit__`。

## 6. 比较与哈希

| 魔法函数 | 触发方式 | 作用 |
|---|---|---|
| `__eq__` | `a == b` | 相等判断 |
| `__ne__` | `a != b` | 不等判断（不实现时自动取 `__eq__` 反值） |
| `__lt__` / `__le__` / `__gt__` / `__ge__` | `<` `<=` `>` `>=` | 大小比较（用于排序 `sorted()`） |
| `__hash__` | `hash(obj)` | 哈希值（对象进集合/字典键需要；实现 `__eq__` 后默认哈希被禁用，需手动补 `__hash__`） |

```python
class User:
    def __init__(self, user_id, name):
        self.user_id = user_id
        self.name = name

    def __eq__(self, other):
        if not isinstance(other, User):
            return NotImplemented
        return self.user_id == other.user_id

    def __hash__(self):
        return hash(self.user_id)

    def __lt__(self, other):
        return self.user_id < other.user_id

    def __repr__(self):
        return f"User({self.user_id}, {self.name})"

u1, u2, u3 = User(1, "a"), User(1, "b"), User(3, "c")
print(u1 == u2)                # True（同 id 视为同人）
print({u1, u3})                # 可进集合 → __hash__
print(sorted([u3, u1]))        # [User(1, a), User(3, c)] → __lt__
```

**重要规则**：
- 实现 `__eq__` 后，Python 会把 `__hash__` 设为 `None`（对象变不可哈希），需要去集合/字典时手动实现
- 想保留默认 `id` 相等语义，别动这两个方法

## 7. 类型转换

| 魔法函数 | 触发方式 | 作用 |
|---|---|---|
| `__bool__` | `bool(obj)`、`if obj` | 真值判断（不实现时用 `__len__`，再没有恒为 True） |
| `__int__` | `int(obj)` | 转整数 |
| `__float__` | `float(obj)` | 转浮点数 |
| `__bytes__` | `bytes(obj)` | 转字节串 |
| `__format__` | `f"{obj}"`、`format(obj, spec)` | 格式化输出 |

```python
class Score:
    def __init__(self, value):
        self.value = value

    def __bool__(self):
        return self.value > 0

    def __int__(self):
        return int(self.value)

    def __float__(self):
        return float(self.value)

    def __format__(self, spec):
        return f"分数: {self.value:.2f}"

s = Score(88.5)
print(bool(s))          # True
print(int(s))           # 88
print(float(s))         # 88.5
print(f"{s}")           # 分数: 88.50
```

## 8. 属性访问

| 魔法函数 | 触发方式 | 作用 |
|---|---|---|
| `__getattr__` | 访问**不存在**的属性时 | 兜底逻辑（如动态生成属性、提示错误） |
| `__setattr__` | 给任意属性赋值时 | 拦截赋值（校验、只读保护） |
| `__delattr__` | `del obj.attr` | 拦截删除 |
| `__getattribute__` | 访问**任何**属性时（无条件） | 最底层的属性钩子，慎用（容易死循环） |

```python
class Config:
    def __init__(self):
        object.__setattr__(self, "_data", {})   # 绕过 __setattr__ 的拦截

    def __getattr__(self, name):
        print(f"属性 {name} 不存在，尝试从配置读取")
        if name in self._data:
            return self._data[name]
        raise AttributeError(f"没有 {name}")

    def __setattr__(self, name, value):
        print(f"设置 {name} = {value}")
        self._data[name] = value

c = Config()
c.host = "127.0.0.1"    # 设置 host = 127.0.0.1 → __setattr__
print(c.host)            # 属性 host 不存在，尝试从配置读取 → __getattr__ 兜底
```

**注意**：在 `__setattr__` / `__getattribute__` 内部不要再直接操作同名属性（会无限递归），用 `object.__setattr__(self, ...)` / `object.__getattribute__(self, ...)`。

## 9. 可调用对象

| 魔法函数 | 触发方式 | 作用 |
|---|---|---|
| `__call__` | `obj(...)` | 让实例像函数一样被调用 |

```python
class Counter:
    def __init__(self):
        self.count = 0

    def __call__(self):
        self.count += 1
        return self.count

counter = Counter()
print(counter())    # 1
print(counter())    # 2
print(counter())    # 3
```

**应用场景**：函数装饰器（保留状态的闭包替代）、可配置的"策略函数"对象。

## 10. 描述符协议

| 魔法函数 | 触发方式 | 作用 |
|---|---|---|
| `__get__` | 通过实例/类访问描述符属性 | 取值 |
| `__set__` | 给描述符属性赋值 | 拦截赋值 |
| `__delete__` | `del obj.attr` | 拦截删除 |

```python
class PositiveNumber:
    """描述符：只允许正数"""
    def __set_name__(self, owner, name):
        self.name = "_" + name

    def __get__(self, instance, owner):
        return getattr(instance, self.name)

    def __set__(self, instance, value):
        if value <= 0:
            raise ValueError("必须是正数")
        setattr(instance, self.name, value)

class Account:
    balance = PositiveNumber()      # 用描述符约束

acc = Account()
acc.balance = 100     # OK
print(acc.balance)    # 100
# acc.balance = -5    # ValueError: 必须是正数
```

**要点**：
- 描述符是 `@property`、`@staticmethod`、`@classmethod` 的底层实现机制
- 实例字典优先于非数据描述符；数据描述符（实现 `__set__`）优先于实例字典

## 速查总表

| 分类 | 魔法函数 | 触发写法 |
|---|---|---|
| 生命周期 | `__new__` `__init__` `__del__` | `类()`、`del obj` |
| 字符串 | `__str__` `__repr__` | `print(obj)`、`repr(obj)` |
| 容器 | `__len__` `__getitem__` `__setitem__` `__delitem__` `__contains__` `__reversed__` | `len()`、`[]`、`in`、`reversed()` |
| 迭代 | `__iter__` `__next__` | `for`、`iter()`、`next()` |
| 上下文 | `__enter__` `__exit__` | `with` 语句 |
| 比较/哈希 | `__eq__` `__ne__` `__lt__` `__le__` `__gt__` `__ge__` `__hash__` | `==`、`!=`、`<`、`>`、`sorted()`、`hash()` |
| 类型转换 | `__bool__` `__int__` `__float__` `__bytes__` `__format__` | `bool()`、`int()`、`float()`、`bytes()`、`f"{x}"` |
| 属性访问 | `__getattr__` `__setattr__` `__delattr__` `__getattribute__` | `obj.attr`、`obj.attr = v`、`del obj.attr` |
| 可调用 | `__call__` | `obj(...)` |
| 描述符 | `__get__` `__set__` `__delete__` | 类属性访问/赋值/删除 |
